# Макеты экранов итогов (30.09.2026) — как воспроизвести

Макет = копия игры во временной папке `dcopy/` (две правленые копии: `index.html`, `js/ui.js`) + скрипты, которые в запущенной игре
подменяют подписи и карточки. В настоящую игру ничего из этого не попадает. Решения владельца — в ЗАДАЧИ.md, раздел «Сейчас», пункт 0.

## Собрать копию игры заново
1. Создать папку `dcopy/js/`, скопировать в неё `index.html` и `js/ui.js` из репозитория.
2. Применить правки: `patch -p0 dcopy/index.html < dcopy-index.diff`, то же для `dcopy-ui.diff` (диффы сделаны с `--strip-trailing-cr`).
   Копия включает режимы daily / relay / caravan / speedrun в новый порядок (`sa=`), карточку места для daily/caravan, CSS «окно растянуто до кнопок».

## Снять режим
- `node snimki2.mjs <папка> <id> <800|700> [патч.js]` — настоящая игра из репозитория (сценарии из tools/worst-case.mjs).
- `node snimki3.mjs <папка> <id> <800|700> <патч.js>` — копия из ./dcopy. В начале файла константа ROOT — поправить путь.
  Сценарии: sa_top_records, sa_deep_rank, relay, caravan, daily, sp_win_deep, sp_win_slower, sp_death, sl_fail, bi_win.

## Патчи (запускаются внутри страницы после сценария)
- hdpatch2d.txt — подписи над числами по очереди. Параметры: `window.__cat` («Касание»…, справа по очереди с «В мире»), `window.__extra` (дополнительные подписи слева: «−60.0 с к рекорду», «Не хватило 1»). Кадр `FRAME` = номер подписи.
- mk11.cjs — собирает p-spw1..4.js (Speedrun, победа) и p-spd1..2.js (Speedrun, смерть) из hdpatch2d.txt.
- p-relay3.js — Эстафета: этапы 1–4 и «Продолжить эстафету» внутри окна, флажок-«конфетка».
- p-car0.js — Caravan: карточка соседа, флажок.
- p-wait.js — печатает положение блоков экрана (проверка высот).
- vy-log-podpisi-na-vy.txt — список подписей, уже переведённых на «вы» (внесено в игру).
