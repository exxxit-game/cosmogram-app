# Права Supabase (REVOKE/GRANT) — success:true не значит, что легло туда, куда думал

Использовать ВСЕГДА, когда создаётся новая функция/RPC в Supabase, или меняются существующие
права (REVOKE/GRANT) на уже созданной. Официальный плагин `supabase` этого урока не содержит
(проверено 29.09.2026: `ALTER DEFAULT PRIVILEGES`/`REVOKE EXECUTE` не упоминаются нигде в его
файлах) — это специфика именно этого проекта, три реальных прокола за один вечер 06.09.2026.

## Три ловушки, каждая поймана вживую

1. **`REVOKE ... FROM anon, authenticated` не срабатывает.** Реальный грант часто висит на
   псевдо-роли `PUBLIC`, не на конкретных ролях — отзыв у конкретных ролей её не трогает.
   Правильно: `REVOKE EXECUTE ... FROM PUBLIC, anon, authenticated` — явно перечислить все три.

2. **У проекта есть `ALTER DEFAULT PRIVILEGES`**, который сам довешивает `anon`/`authenticated`
   НОВЫМ функциям при создании. Значит для НОВОЙ функции недостаточно REVOKE постфактум —
   `REVOKE EXECUTE ... FROM PUBLIC, anon, authenticated` пишется В ТОЙ ЖЕ миграции, что и
   `CREATE FUNCTION`, одним куском, не отдельным следующим шагом.

3. **Попытка перевернуть умолчание для всей схемы разом сработает только частично** — есть
   второй, не наш `pg_default_acl` (`supabase_admin`), который мы поменять не можем. Не
   рассчитывать, что один общий `ALTER DEFAULT PRIVILEGES` на схему решит вопрос навсегда для
   абсолютно всех новых объектов.

## Обязательная проверка после — success:true ничего не доказывает

После ЛЮБОГО REVOKE/GRANT (не важно, показал ли вызов успех):

1. Перечитать реальные права из `information_schema.role_routine_grants` — не верить статусу
   выполнения команды.
2. Подтвердить `curl` настоящим анонимным ключом — ждать `42501 permission denied`, не просто
   отсутствие ошибки в ответе SQL-вызова.

## Формула для новой функции

```sql
create function public.my_new_function(...) ... as $$ ... $$;
revoke execute on function public.my_new_function from public, anon, authenticated;
```
Обе строки — в одной миграции. Затем шаги проверки выше, в этом же ходу, не отложенным шагом.
