description: Собрать финальный шаг правки игры (версия→страж→коммит) в одну процедуру вместо разрозненных вызовов подряд
---
16.09.2026 (исследование по просьбе владельца — уменьшить количество повторяющихся ручных
шагов на каждую правку): было 3-5 отдельных вызовов на каждую правку игрового файла (Edit
core.js вручную, sed по 23 тегам, Edit sw.js, потом отдельно guard.mjs, потом git add, потом
commit) — реальный источник и потраченного времени, и риска пропустить шаг под спешкой.
Ниже — одна процедура, не новая проверка сверх того, что уже было договорено раньше в сессии.

Выполняй по порядку, без переспрашивания на каждый шаг (это финальная сборка уже сделанной
и согласованной правки, не новое решение):

1. `git status --short` в затронутом репозитории (`cosmogram-app` и/или `cosmogram-crew`) —
   свериться, что именно изменилось, прежде чем стейджить.
2. Если среди изменений есть игровые файлы (`index.html`, `js/*.js`, `sw.js`) —
   `node tools/bump-version.mjs` (один вызов вместо трёх правок).
3. Стражи — НЕ весь набор по умолчанию:
   - если правка узкая и страж под неё уже есть/только что написан — `node tests/guard.mjs --only=<имя_функции_или_номер>`;
   - полный `node tests/guard.mjs` (GAME_ROOT=../cosmogram-app при запуске из cosmogram-crew) —
     только если это последний шаг перед закрытием задачи/сессии, не после каждой мелкой правки
     ([[feedback_guard_only_flag]]).
   - перед любым полным прогоном — он теперь сам откажет, если предыдущий ещё не завершился
     (`.guard.lock`), это не нужно проверять руками отдельно.
4. Показать владельцу «было → стало» по каждому реально изменённому файлу (не по всем
   попутно тронутым чужой параллельной сессией — свериться через `git diff`, что именно моё).
5. `git add <явные пути>` — никогда `-A`/`.` (теперь и технически заблокировано хуком).
6. `git commit` с сообщением на русском, тем же стилем, что в истории репозитория (почему,
   не только что), с co-authorship строкой из системного напоминания. `git push` — НИКОГДА,
   это делает владелец сам.

Если задача выполнена сразу в двух репозиториях (cosmogram-app игровой файл + cosmogram-crew
guard.mjs) — два раздельных коммита, каждый в своём репозитории, не один смешанный.
