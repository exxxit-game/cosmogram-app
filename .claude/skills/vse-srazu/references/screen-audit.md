# Все переменные сразу: файл требований и матрица языков

Вынесено из `SKILL.md`. Сложная задача — это несколько требований одновременно. Правка по одному («поправил это, посмотрел, поправил то») ходит по кругу: починенное здесь ломается там.

1. Для экрана лежит файл требований `tools/screen-specs/<экран>.json` (допуски: равная высота, нет пустот, растяжение строк, вылезания, наложения, «выглядывает следующая»). Файла нет: сначала написать его из слов владельца, потом править.
2. Запуск: `node tools/screen-audit.mjs --spec=tools/screen-specs/<экран>.json`. Матрица «размер экрана (360×800, 360×700) × все языки» (`tools/screen-specs/languages.json`: китайский, японский, тайский без пробелов; арабский, иврит справа налево; хинди; немецкие слитные слова; финский; «предел +50%»). Печатает таблицу и «что где не держится».
3. Конфликт требований называть вслух. Установленный факт: подбор стиля под слова иногда ничего не даёт (4416 сочетаний ширины, шрифта, интервала: ни одного с равными карточками на русских словах); тогда нужна вёрстка, подстраивающаяся под любую длину, а не подгонка.
4. **Данные, которые меняются** (рекорды, счётчики, ники, места, время; владелец: «ты берёшь самый простой вариант, а потом выясняется, что на самом сложном надо кучу правок»). Для таких полей в файле требований есть `dynamic` (селектор и класс данных) и `cases` (`zero`, `typical`, `heavy`, `widest`). Значения лежат в `tools/data-fixtures.json` с источником у каждого потолка (правило ника ≤10 знаков, рекорды владельца × запас роста, `worst-case-fixtures.json`). Инструмент подставляет их и ищет: обрезано, вылезло из блока, за краем экрана, перенеслось на вторую строку. Статичный текст (Хартия и т. п.) в эту проверку не идёт. В макете рисовать рядом с типичным значением тяжёлое и самое широкое. Находку чинить в самой игре, не в допуске.
5. Быстрый режим для одного состояния: `node tools/screen-audit.mjs <экран> --cards=.селектор`.
6. Ложное срабатывание инструмента: чинить сам инструмент, а не отмахиваться и не подгонять допуски. «Предел устойчивости» (`"limit": true` в профиле языка) только для крайних случаев, не для реальных языков.
Каждое замечание: починить или назвать, почему это задуманный отступ (заголовок → панель, разделитель перед подписью). «Красиво» инструмент не измеряет: глаза на снимок остаются.
