# Новые языки и письменности

Игра переводится на все языки мира. У слов это самая лёгкая часть; ломаются шрифты, направление письма, переносы, длина строк, числа и позывные. Полный чек-лист из 22 пунктов, размеры шрифтов, план из 14 шагов и порядок языков: `references/chek-list.md`. Читать до первого шага.

## Порядок

1. **Решение владельца до кода:** какой язык, кто носитель (без носителя тон и формы вежливости не проверить), зеркалить ли меню, как быть с позывными (сейчас только латиница и кириллица). Вопросом с вариантами.
2. **Идти по плану из `references/chek-list.md`:** код языка и словарь, формы «n штук» (`Intl.PluralRules`), шрифты и правила `:lang()`, `dir`, canvas (строка целиком, `Intl.Segmenter`), числа и даты, проверка «тофу» (пустых квадратов) по всем знакам словаря.
3. **Мерить, а не смотреть на глаз:** `node tools/screen-audit.mjs --spec=tools/screen-specs/<экран>.json` на 360×800 и 360×700 с профилем нового языка (в `tools/screen-specs/languages.json` добавить `lang`); снимки; проверка на телефоне владельца.
4. **Тексты вычитывает носитель** (карточка MQM: термины, точность, стиль, местные условности, оформление). Машинный перевод только как черновик; Хартию и научные факты скинов без носителя не переводить.
5. **Визуальное через макет** (скилл `maket`): новый шрифт и зеркальное меню видит игрок; самый длинный язык (немецкий, финский, португальский) и самый высокий шрифт (хинди, тайский, вьетнамский) показывать рядом.

## Чего не делать

- Не подключать внешние библиотеки перевода и сервисы (правило «без новых зависимостей»; строки уходили бы наружу). Идеи брать (Pretext, BudouX, Fluent), код подключать только с отдельного слова.
- Не резать строку по пробелам и не рисовать по символам на canvas для арабского, иврита, индийских письменностей и тайского.
- Не включать `letter-spacing` и заглавные буквы для арабского.
- Не добавлять языки массово: по одному, каждый с проверкой на телефоне.
- Сырой `language_code` в отчёты и новые языки в `SUPPORTED_LANGS` — изменения кода, только по слову владельца.
