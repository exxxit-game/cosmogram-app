# Как обновить систему дизайна по живой игре (опыт 02.10.2026)

Первый ручной проход (26.09) описывал экраны по памяти, и к 02.10 они устарели: старые карточки опирались на классы, которых в игре уже не было (`.btn.gold`, `.achIt`, «+N ✦»). Процедура ниже даёт карточки, которые совпадают с игрой. Скрипты 02.10 лежали во временной папке сессии и не сохранены; при повторе переписать по описанию.

1. **Стили целиком.** `components/bundle.css` = базовая обёртка `.cg` + весь CSS игры из `<style>` в `index.html`, без `@font-face` (шрифты даёт `tokens.css`) и без правил `html, body` (фон и размер задаёт превью). Тогда карточки не расходятся со стилями.
2. **Разметка экранов из живой игры.** Playwright открывает локальную игру 360×800, для каждого экрана вызывает функцию открытия (`setScreen(...)` с наполнением: `renderAch()`, `renderHangar()`, `forgeOpen()` и т. д.), ждёт и берёт `outerHTML` корня экрана. Итоги полёта получаются вызовом `startGame(); …; gameOver()` с подставленными `S.mode`, `S.score`, `rec`. Данные примерные; пометить в README: «гость, примерные данные».
3. **Значки и эмблемы.** В превью подтянуть только те `<symbol>`, `<linearGradient>`, `<filter>`, `<clipPath>`, на которые ссылается разметка (`href="#…"`, `url(#…)`), включая зависимости. Скрипты, комментарии и `on…`-атрибуты убрать.
4. **Корень экрана в превью:** `.cg > .overlay { position: relative !important; inset: auto !important; width: 360px !important; height: 800px !important; }`, чтобы экран не улетал в `fixed`. Превью не больше 256 КБ (Конструктор ~73 КБ).
5. **Старые карточки:** сравнить селекторы старого `bundle.css` с CSS игры; пропавшие селекторы — устаревшие карточки. Заново собрать их из реальных фрагментов (кнопки, чипы, вкладки, плитки), а не чинить по памяти. Неиспользуемое (например `AchievementItem`) не удалять: перечислить владельцу и спросить.
6. **Токены.** Проверить, что значение каждого токена ещё встречается в CSS игры; не найденные перечислить владельцу, не удалять молча.
7. **Проверка перед публикацией:** отрисовать каждое превью локально с теми же токенами и шрифтами и посмотреть снимки глазами. Сама страница системы требует вход в claude.ai, из браузера сессии её не открыть: так и писать «страницу системы не смотрел».
8. **Публикация:** файлы одним вызовом, индекс `project/design-system.json` отдельным последним; перед записью перечитать каждый файл, чтобы убедиться, что его никто не менял (версия артефакта та же). После публикации прочитать обратно и сверить sha256.
