# 🌍 Многоязычный поиск свежих идей (07.09.2026)

> Задача владельца: «на всех языках мира ищи, используй коннекторы, узнай, есть ли более
> свежие, неизвестные нам способы улучшить игру — не банальщина». Четыре параллельных
> фоновых агента: (1) платформа Telegram, (2) неанглоязычный геймдев (рус/яп/кор/кит/нем/фр),
> (3) свежий геймдев и техника 2025-2026, (4) этичная монетизация и экономика авторов.
> Каждый обязан был цитировать источник+дату на каждое утверждение — здесь только то,
> что реально подтвердилось.

## 🔴 Проверить как можно скорее (не идея — потенциальный живой баг)

**С 20.07.2026 Telegram по умолчанию блокирует вызовы методов Mini App API с домена,
отличного от исходного домена мини-аппа** (Bot API 10.2/10.3, официальный changelog:
core.telegram.org/bots/api-changelog — «disallowing usage of Mini App methods from
origins different from the original Mini App domain»). Если где-то в OAuth-флоу
Google/Discord есть редирект/iframe на другой поддомен (см. [[project_oauth_post_timeout_fix]]) —
методы WebApp API там могли молча перестать работать именно с этой даты. Нужен один
живой тест входа через Discord/Google на реальном Telegram-клиенте, не чтение кода.

## 1. Механики (геймплей/социальность)

- **Асинхронный «вызов-карточка» вместо реал-тайм PK — виральность в 5+ раз выше**
  (Tencent News, кит., 20.01.2026, news.qq.com/rain/a/20260120A07CLX00). Дословная цифра:
  тот же геймплей, но без требования одновременного онлайна, дал в 5+ раз выше коэффициент
  расшаривания — координационные издержки убивают виральность сильнее, чем кажется.
  Применимо к Вызову (Дуэли) и Дрейферу/Ловцу — уже есть призраки, можно явно подать как
  карточку-вызов «сыграй когда удобно», а не только через таблицу лидеров.
- **Агрегатное статистическое присутствие («68% игроков выбрали...»)** — таксономия из
  японского блога note.com/planetary_gear/n/neb3b6c26e319: три типа асинхронного
  «присутствия» других игроков — оставленные следы (уже есть, призраки), агрегатная
  статистика (нет), чистый факт присутствия (уже есть). Дёшево прикрутить к «Небу месяца»:
  «68% пилотов в этом небе свернули влево у первой кометы».
- **Гошуин (御朱印) — японская традиция храмовой печати**: ценность не в «собери всё»,
  а в уникальной, недублируемой, лично засвидетельствованной метке момента (мастер
  рисует печать вручную при тебе, с датой). Для «Неба месяца»: генеративная метка дня,
  которая рисуется один раз, привязана к дате+игроку, и её нельзя перевыпустить или
  купить — ценность именно в неповторимости.
- **Постоянный «назначенный напарник»** (не случайный призрак, а конкретный друг,
  отдельная от лидерборда механика) — из китайского разбора соцмеханик мини-игр
  (jiemian.com/article/11844114.html). Сейчас в Cosmogram нет способа двум конкретным
  друзьям взять на себя регулярную совместную структуру (Эстафета — цепочка на многих,
  не пара).
- Русские, корейские, немецкие и французские источники в этом заходе дали только
  стандартные вещи (архетипы игроков, сезонные события) — агент честно об этом написал,
  не стал натягивать находки.

## 2. Платформа Telegram

- **`sendGift`** — бот может тратить заработанные Stars, чтобы подарить игроку настоящий
  передаваемый TON-NFT-подарок (core.telegram.org/bots/features, gramio.dev). Не лутбокс:
  это честная награда по месту в рейтинге, но это реальный актив, а не циферка в БД.
  Есть `pay_for_upgrade` — можно оплатить апгрейд подарка, чтобы игроку он достался
  уже улучшенным бесплатно.
- **`setEmojiStatus`** (Bot API 8.0+, ноябрь 2024, отсутствует в текущей базе TELEGRAM-GOTCHAS.md) —
  эмодзи-статус игрока виден во ВСЁМ Telegram (любой чат, поиск людей), не только в игре.
  Бесплатный органический канал видимости за пределами игры, доброволен (permission popup),
  чистая косметика.
- **`BotSubscriptionUpdated`** (Bot API 10.2, 14.07.2026) — официальный вебхук жизненного
  цикла Stars-подписок. Готовая инфраструктура, если тема «поддержки разработчика»
  когда-нибудь вернётся (см. [[project_monetizatsiya_dosug_obsuzhdenie]]).
  - Ничего новее Bot API 10.3 (24.08.2026) физически не существует на 07.09.2026 —
  проверено по официальному changelog, не выдумано.

## 3. Техника/производительность

- **Canvas2D Layers API** (`beginLayer()`/`endLayer()`) — новый, ещё внедряемый браузерный
  примитив (chromestatus.com/feature/5629802309484544, github.com/fserb/canvas2D,
  Chromium issue 40185317). Позволяет одним фильтром/блендингом/тенью накрыть ГРУППУ
  команд рисования как единый композитный слой — вместо ручного офскрин-канваса на
  каждый эффект. Прямо ложится на trail/flash-эффекты в `render.js` (тот же класс задачи,
  что решали этой сессией через `trailGlow()`/`sfUnitPts()`-кэши). Перед применением —
  обязательно замерить реальный прирост на слабом Android, не на глаз.
- **«Орбитальные плитки Труше»** (Truchet tiles на сфере) — Matt Zucker, конференция
  Bridges 2025 Eindhoven, июль 2025 (mzucker.github.io/2025/03/15/squiggle-orbs.html).
  Классические плоские плитки Труше, перенесённые на сферические многогранники.
  Потенциальный новый формула-стиль для скинов/вспышек — но это шейдерная/CAD-идея,
  2D Canvas-математику под неё нужно вывести и численно проверить с нуля, не копировать.

## 4. Позиционирование / этичная монетизация

- **Balatro: публичный отказ от микротранзакций стал бесплатным вирусным PR** — пост
  LocalThunk в Bluesky («это хищничество»), плюс пункт в завещании, запрещающий IP
  когда-либо перейти гэмблинг-компании — разошёлся по PC Gamer, GamesRadar+, Rolling
  Stone в 2025-2026. Ближайший реальный прецедент «манифест как маркетинг». Хартия
  Cosmogram, процитированная одним острым постом («вот пункт, который запрещает X
  навсегда») — бесплатный PR-актив с нулевой стоимостью.
- **Hazelight (Джозеф Фарес): «никаких лутбоксов, микротранзакций, чуши» — повторяется
  из года в год на каждой церемонии The Game Awards**, стало частью бренда именно за
  счёт повторения, не разового поста (thegamer.com, gameshub.com).
- **Deep Rock Galactic: «купи этот чисто косметический набор, чтобы поддержать нас» —
  вместо поднятия цены игры** — выросла с ожидаемых 200к до 8М+ копий, 97% положительных
  отзывов, без лутбоксов и FOMO-магазина (pcgamer.com, gameworldobserver.com). Применимо
  к Тюнингу: подавать наборы за Stars явно как «поддержи студию» под конкретный дроп
  контента (новые Вспышки/Следы/скины), а не как оторванный магазин.
- **HoYoverse (Genshin) отказались от гача в новой игре «Nodusfall» после штрафа FTC
  $20M и падения мобильной выручки Genshin на 48%** (techtimes.com, 28.08.2026). Признание
  крупнейшей гача-студии рынка, что модель несёт реальный риск — аргумент в пользу
  уже принятого запрета лутбоксов в Хартии, не новая инструкция.
- **Geometry Dash Creator Points** — ручная курация уровней сообщества по тирам
  (Feature/Epic/Legendary/Mythic), не деньги, а статус/репутация
  (robtopgames.com/files/GDRating.pdf). Ровно та лёгкая модель, которая нужна Мастерской:
  нефинансовый тир-бейдж для выдающихся уровней сверх счётчика лайков — без денег и без
  «настоящих авторов»-инфраструктуры, о которой ранее шла речь при отклонении реакций
  ([[project_masterskaya_kommentarii_avtoram]]).
- **Trackmania «Трасса дня»** — 20+ лет непрерывной ротации одной трассы сообщества в
  центре внимания, привязана к отдельному внутриигровому событию (doc.trackmania.com).
  Проверенная модель ротации «уровень дня/недели» на витрине Мастерской.
- **Telegram Stars — скрытый налог платформы ≈46%**: покупка 100 Stars стоит игроку
  $2.40, а разработчик обналичивает эти Stars по курсу ≈$0.013/Star ($1.30) — комиссия
  Apple/Google (15-30%) ложится поверх собственного спреда Telegram (wnhub.io, 2025-2026,
  точный процент по платформам не найден — не подтверждено). Ориентир на будущее: при
  любом ценообразовании закладывать, что реально остаётся примерно половина уплаченного.
  Конверсия в покупку через Mini App ≈8.2% — втрое выше мобильного веба (vc.ru/crypto/2932690).

## 5. Проверка уникальности «формулы как скины» (08.09.2026, отдельный заход по просьбе владельца)

- **Прямого конкурента не нашли** ни на одном из 6 языков (англ/яп/кит/кор/нем/рус) — ни одна
  игра не продаёт скины КАК настоящие именованные формулы с численной проверкой.
- **Но сам инсайт «наука может быть красивой вещью, которую можно иметь» — НЕ новый**: Spirograph
  (1965, Hasbro, настоящие гипотрохоиды), молекулярные украшения (серотонин/ДНК/кофеин как
  кулоны, целая розничная ниша), украшения с диаграммами Вороного — всё это продаётся десятилетиями
  именно на факте «это настоящая наука». Честная подача для прессы: «первые, кто принёс это в
  игровую экономику скинов», не «первые, кто понял, что наука красива» — вторая фраза не выдержит
  проверки.
- **Прямой прецедент того, что такая подача работает у прессы**: Engare (Иран, соло-разработчик
  Mahdi Bahrami) — головоломка на настоящей геометрии исламского искусства, освещение в Engadget/
  Fast Company/Hyperallergic, номинации IGF/IndieCade/GDC. Monument Valley — на реальной геометрии
  Эшера/Пенроуза, в коллекции MoMA, 26М+ копий. 3Blue1Brown (6.4М подписчиков) — «красивая
  визуализация настоящей математики» уже признанный журналистами жанр. DragonBox Algebra — NYT
  назвал «самым впечатляющим математическим приложением», учит алгебре без единой цифры на экране.
- **Тактика питча прессе**: журналисты получают 50-100 питчей в день, заходит один чёткий проверяемый
  факт («каждый скин — численно проверенная настоящая формула»), не общее «у нас красивые скины».
  Пример: Unexplored получил статью в Rock Paper Shotgun из одного конкретного факта дизайна.

  не подтверждено.
