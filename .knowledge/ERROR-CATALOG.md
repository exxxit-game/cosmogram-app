# 📜 Каталог боевых ошибок и рождённых законов (Error Catalog)

> **Правило:** Пополняется при «боевом крещении» — когда понятен корень, а не симптом.

---
- **Страж пишется до правки и обязан сначала покраснеть.** Страж, который не поймал
  существующую беду, ничего не охраняет.
- **Плавающий страж хуже отсутствующего.** Прогон ×3 поймал двух таких — переписаны
  на опрос состояния.
- **Страж может дать ложную зелень.** Проверяй, что сценарий действительно включился,
  а не просто не упал.
- **Малая выборка — не доказательство.** Считай на дистанции, где шум меньше эффекта.
- **Комментарий ставится ПЕРЕД строкой, а не после неё.** Однострочный `//` в конце
  строки, закрывающей блок, — запрещён: дважды съедал закрывающую скобку.
- **Свои правки надо проверять чужими глазами.** Восемь регрессий нашла только
  враждебная проверка дифа, а не собственная перечитка.


## 1. Топ-10 ключевых законов из аудитов

1. **Закон К1 (Идеальная тишина):** Идеальная неподвижность канала гироскопа — повод для подозрения на зависание, а не признак идеального нуля.
2. **Закон К2 (Разделение осей):** Складывать $\Delta\gamma + \Delta\beta$ в один скаляр нельзя: диагональный наклон даёт ноль и ложно считает канал мёртвым.
3. **Закон К3 (Очередь запросов):** Если сабмит призрака проверяется по результату рекорда, запросы обязаны идти строго последовательно.
4. **Закон К4 (HTTP 200 $\ne$ успех):** Серверный ответ 200 `{quiet: true}` означает вежливый отказ по антиспаму, а не сохранение записи.
5. **Закон К5 (Пустой catch):** Пустой catch вокруг записи в `localStorage` — это молчаливая потеря прогресса при превышении квоты.
6. **Закон К6 (Время соревнований):** Общие турниры и Трасса дня меряются строго по **UTC**, а личные дни игрока — по местному времени.
7. **Закон К7 (Изоляция схем Supabase):** Все аналитические представления (views) выносятся в схему `analytics` с `security_invoker = true`.
8. **Закон К8 (Проверка входа геометрии):** В момент изменения размера вьюпорт может кратковременно вернуть 0×0. `resize()` обязан отсекать нули.
9. **Закон К9 (Канвас не слышит CSS):** Стили `text-transform: uppercase` не влияют на `ctx.fillText()`. Регистр текста приводится кодом вручную.
10. **Закон К10 (Синхронность кэшбастера):** Запуск `bump_version.py` — обязательный финальный шаг каждого релиза для синхронизации `sw.js`, `?v=` и `GAME_VERSION`.

## Новые законы (из исследований 2026)

11. **Закон К11 (Батчинг маяков):** Одно письмо — один запрос ведёт к быстрому исчерпанию лимитов; батчинг обязателен для масштабирования.

12. **Закон К12 (Пассивные слушатели):** Пассивные слушатели `touchstart` могут давать задержку 300 мс на Android; используйте `{passive: false}` с `preventDefault()`.

13. **Закон К13 (Интерполяция остатка):** Для плавности на высокой частоте обновления (120+ Гц) используйте alpha-интерполяцию между тиками при рендеринге.

14. **Закон К14 (alpha: false):** Контекст создаётся с `alpha: false` для непрозрачного фона. Полный разбор — PERFORMANCE.md §2.14.
15. **Закон К15 (Кэш Path2D):** Силуэты кэшируются при спавне. Полный разбор — PERFORMANCE.md §2.12. Дубликат удалён.
16. **Закон К16 (shadowBlur):** Дорог на высоком DPR; только предрендер свечений. Полный разбор — PERFORMANCE.md §2.13. 

- **К4 (уточнено 17.08.2026):** кейс «200 {quiet:true}» из «Каталога ошибок» №9 относится к
  пути «Почты неба» (beacon). В пути рекордов (cosmogram-sync) антиспам — явный HTTP 429
  {error:'rate'}, клиент на 429 оставляет разовые поля (см. D1). Закон «HTTP 200 = запрос
  дошёл, а не дело сделано» остаётся: проверить skymail.js, читает ли клиент тело/quiet.
