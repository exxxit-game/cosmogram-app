## B. Диагностированные долги ядра (сверено с живым кодом 24.08.2026)

### Открыто — подтверждено, актуально

- **Мигающая точка около «жизней» (видео владельца, 26.08.2026).** Не найдена. Проверена и
  отклонена одна гипотеза — рамка коридора `.corrEdge`/`corridorEdgeSprite()`: показывается
  только когда `fieldL()>0` (экран шире 390-мерного коридора), а на телефоне `fieldL()=0`
  всегда — рамка физически не может рисоваться там, откуда снято видео владельца. Нужен
  свежий скрин/видео с телефона на текущей версии, чтобы искать заново по доказательству, а
  не по гипотезе.
- **`audio_never_resumed: suspended`.** Сигнал реально приходит (живой beacon 26.08.2026,
  Linux armv81) — `AudioContext.resume()` на этом устройстве/браузере не отклоняется и не
  срабатывает вовсе. Похоже на ограничение автополитики конкретной платформы, не на баг в
  нашем коде; корень не найден, вслепую не чинили. Диагностика уже стоит (24.08.2026,
  `audioResumeFailReported`/`audioNeverResumedReported`) — ждём больше живых данных.
- **Потолки дистанции: `CAPS.dist=2 000 000`** (рекорды, сервер) vs `20 000 000`
  (`readDays`/дневник) — два потолка в одной функции, не унифицированы. Физический предел
  ~1 797 120 м даёт запас ~11%, сегодня не мешает — пересчитать при добавлении ускорений.
  Низкий приоритет, осознанно отложено.
- Идеи на будущее без изменений: Web Share API вне Telegram, Pointer Lock для мыши,
  геймпад-вибрация, переназначение клавиш, «Станция Планетария» не доведена до работы,
  кэшбастер без режима «покажи и не пиши».
