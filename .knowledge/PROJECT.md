## 1. Суть игры

**Cosmogram** — бесконечный вертикальный космический раннер-уклонялка без стрельбы с бумажным самолётиком, детерминированной процедурной трассой, атмосферной космической эстетикой, процедурным Web Audio звуком и соревновательной экосистемой в Telegram.

Игрок уворачивается от астероидов трёх минеральных тонов, спутников и комет, собирает золотые звёзды, строит комбо-цепочки, поддерживает шкалу «Плавности» и активирует 6 тактических бонусов.

### Ключевые столпы

1. **Чистое уклонение и сбор:** ноль стрельбы. Мастерство — реакция, траектория, зазор near-miss, проход через узкие гравитационные ворота.
2. **Одно небо для всех экранов:** эталон **390×844** мер, честное масштабирование под любые пропорции. Один `seed` = одинаковая геометрия на телефоне, мониторе и ТВ. «Потолок листа» — максимум 2560 px по длинной стороне.
3. **Пять штурвалов:** палец, наклон телефона («Полёт без рук» + Суд компасов), мышь с зажатой кнопкой, клавиатура (стрелки и WASD в обеих раскладках), геймпад.
4. **Морзянка в небе и в ладони:** позывной тянется шлейфом глифов и отстукивается виброэфиром (точка 50 мс, тире 150 мс).
5. **Живое небо «Планетарий»:** процедурные метеоры, маяки, станции со светом и дымом, отметины пути, искры золотых звёзд.

## 2. Стек технологий

Проект сознательно избегает фреймворков (Phaser, PixiJS, Three.js, Unity WebGL) и бандлеров ради мгновенной загрузки, читаемости («код читается как книга») и контроля кадрового бюджета.

| Слой | Технология |
|---|---|
| Рендеринг | HTML5 Canvas 2D, спрайтовое кеширование свечений, Path2D-кэш силуэтов |
| Язык | **Vanilla JS (ES2022+) — чистый JavaScript.** Упоминания TypeScript в старых версиях этого файла устарели: боевой код — только `.js`, без компиляции |
| Звук | Web Audio API, 100% процедурный синтез — ноль аудиофайлов |
| Детерминизм | `withTrack` + Seeded PRNG (Mulberry32) по категориям спавна |
| Офлайн/доставка | Service Worker лежит в репозитории, но **PWA выключен осознанно** («до поры», v1.20.0). Возврат — продуктовое решение владельца |
| Облачный синк | Supabase Edge + CloudStorage, паспорт забега, серверная верификация |
| Платформа | Telegram WebApp API (HapticFeedback, Safe Area, shareToStory, CloudStorage) |
| Память | Zero-Allocation пулы: `POOL_CAP=64` (препятствия, звёзды), 16 (бонусы), `PARTICLE_CAP=120..220` по тиру, 32 (очки) |

## 3. Хартия неба и ценности

Полный текст — в `CHARTER.md` (v2.0 «Одно небо для всех», 47 статей). Сжато:

- Каждый элемент проходит **Суд четырёх вопросов**: улучшает ли игру? читается ли с полёта? не пугает ли зря? не крадёт ли кадры?
- **Равноправие:** нельзя купить победу; нет рекламы, лутбоксов и тёмных паттернов.
- **Масштабируются только украшения:** физика, скорость и коридоры одинаковы для всех устройств.
- **Честность рекордов:** знак подтверждения — только после серверной верификации; планка дуэли живёт на сервере.
- **Монетизация — благодарность, а не власть** (отчёт v3): Стена благодарности, Корона дня (NFT/TON, оплата только гравировки), косметика без влияния на исход. Любая форма проходит суд Хартии.
- **Стражи раньше кода:** тест до реализации (красный → зелёный), прогон трижды перед сдачей.
- **Ритуал разработки:** один модуль ≈ 200 строк = один коммит = один пуш.

## 4. Режимы полёта

- **Классика** — бесконечный полёт на личный рекорд (категории: touch / gyro / keys / bullet / dist).
- **Трасса дня** — единый эталонный коридор с суточным UTC-сидом, одна попытка в сутки.
- **Затишье** (bullet) — свободный полёт без препятствий; отдельная категория рекорда.
- **Спидран** — заезд на скорость до 10 000 очков.
- **Своя трасса / Кузница** — конструктор неба с пресетами и кодами `CG1.*` (customLv).
- **Театр призраков** — детерминированный автопилот по чужой ленте; дверь «смотреть»
  открывается только при сиде владельца (страж 126), небо ставится владельца.
- **Дуэль** — призрак вызова по pid, планка живёт на сервере.

Удалено (по сверке с кодом v1.400.2, 17.08.2026): имена «Витрина режимов» с пунктами
«Затишье, Касание, Таран, Замедление, Коридор ворот» — в коде отсутствуют как режимы.

## 5. Шесть бонусов

| Бонус | Длительность | Механика |
|---|---|---|
| Щит | 14 с | Поглощает один удар |
| Магнит | 12 с | Притягивает звёзды в радиус 220 px |
| Слоумо (старое имя: Замедление) | 6 с | `timeScale = 0.5` |
| Таран | 4 с | Крушит препятствия (+50 × mult) |
| Жизнь | мгновенно | +1 жизнь (лимит 3) |
| Сверхновая | мгновенно | Сжигает препятствия на экране (+100 × mult), сайдчейн звука |
