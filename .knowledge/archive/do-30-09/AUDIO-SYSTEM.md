## 2. Ключевые звуковые генераторы (`js/music.js`)

### А. Звук сбора звезды (Coin & Combo Pitch):
Тембр монеты динамически повышается по пентатонической шкале в зависимости от текущего множителя комбо `S.combo`:
```javascript
// Частота растет с комбо (от 520 Hz до 1040 Hz)
const baseFreq = 523.25; // Note C5
const freq = baseFreq * Math.pow(1.059463, Math.min(combo, 10) * 2);
osc.frequency.setValueAtTime(freq, ctx.currentTime);
osc.frequency.exponentialRampToValueAtTime(freq * 1.5, ctx.currentTime + 0.08);
```

### Б. Сайдчейн компрессия (Music Ducking):
При активации Сверхновой (`nova`) или при получении урона музыка кратковременно приглушается (`music.kick()`), передавая физический вес событию:
```javascript
musicGain.gain.setValueAtTime(0.15, ctx.currentTime);
musicGain.gain.exponentialRampToValueAtTime(1.0, ctx.currentTime + 0.8);
```

### В. Буферы шума (Noise Generators):
Для симуляции ветра, реактивного гула тарана и космических аномалий используется предгенерированный статический буфер белого/розового шума `noiseBuf`, модулируемый через `BiquadFilterNode` (Bandpass / Lowpass).

### Г. Тактильный виброэфир (Haptic-Audio Sync):
Синтез аудио синхронизирован с вибромотором смартфона:
- Точка морзянки: звук 800 Hz (50 мс) + вибрация 50 мс.
- Тире морзянки: звук 800 Hz (150 мс) + вибрация 150 мс.
- Near-miss («впритык»): тихий высокочастотный щелчок + легкий импульс `HapticFeedback.impactOccurred('light')`.

## 3. Политика автовоспроизведения (Autoplay Policy)

Мобильные браузеры (iOS Safari, Android Chrome) блокируют запуск звука до первого явного жеста пользователя:
1. `AudioContext` создается в состоянии `'suspended'`.
2. На `pointerdown`, `touchstart` или `keydown` вызывается `audioContext.resume()`.
3. Дополнительно сторож проверяет состояние `'interrupted'` (при входящих звонках на iOS) и безопасно восстанавливает синтез после возвращения в игру.

## 4. Особенности платформы (дополнено 2026)

### 4.1 AudioContext не всегда возобновляется после фона на iOS
- Открытый баг WebKit: после возврата из фона состояние `running`, но `currentTime` не увеличивается.  
- **Решение:** на каждое `visibilitychange` → `visible` явно вызывать `audioContext.resume()` и проверять `currentTime` через несколько секунд.

### 4.2 Физический переключатель «Тишина» на iPhone
- Блокирует весь Web Audio без возможности программного обхода.  
- **Решение:** добавить UI-подсказку и не полагаться только на звук для критических событий.

### 4.3 Задержка Bluetooth-аудио
- На Android/Chrome задержка может достигать сотен мс через Bluetooth-наушники.  
- Не проектируйте геймплей, требующий миллисекундной синхронизации звука с действием.

### 4.4 Тактильная обратная связь
> Единственный источник — ACCESSIBILITY-GUIDE.md §7 (iOS: `navigator.vibrate()` не работает; Android: `Telegram.WebApp.HapticFeedback` нестабилен; гаптика не бывает единственным каналом). Здесь правило не дублируется.

### 4.5 Референс ZzFX
- Компактный генератор звуков (менее 1 КБ) — может служить примером для унификации параметров SFX.

### 4.6 Квантование по такту (как в Rez)
- Действия игрока (сбор звезды, near-miss) можно синхронизировать с музыкальным тактом, чтобы звук всегда попадал в ритм, даже если нажатие неточное. Это повышает ощущение цельности.

### 4.7 Нижняя граница слышимости на динамике телефона (урок из истории проекта, 27.08.2026)
- Фоновая музыка изначально была заложена в диапазоне 110–165Hz — на телефонном
  динамике (без наушников) это почти не слышно, штатный частотный отклик малых
  динамиков резко проседает ниже ~200Hz.
- **Правило:** держать основной корень/дрон процедурной музыки не ниже **220Hz**, и
  закладывать запас громкости по каждому голосу отдельно (+40–50% к «студийному» уровню
  каждого осциллятора) — то, что звучит сбалансированно в наушниках, на встроенном
  динамике может быть неразличимо тише остальных слоёв.
- **Проверено численно 27.08.2026:** `DRONE_ROOTS` в `music.js` даёт для нижней ноты ровно
  MIDI 57 → `440×2^((57-69)/12)=220Hz` — точно на границе правила, не ниже. Правило соблюдается.

# 🎵 Процедурный звуковой дизайн и эмбиент-генератор

> **Стандарт:** Web Audio API Procedural Synthesis (100% On-Board / Zero Audio Files)  
> **Миссия:** Музыка — это не зацикленная песня, а живой космический ландшафт.

---

## 1. Философия бесконечного звука (Brian Eno Ambient Architecture)

Зацикленный саундтрек приедается за 10–20 повторов. Процедурный эмбиент Cosmogram строится на трёх законах:

1. **Минорная пентатоника (A-C-D-E-G):** Полное отсутствие полутонов и резких диссонансов создаёт ощущение пустоты и невесомости.
2. **Плывущий центр (Drifting Root):** Базовый низкочастотный дрон медленно и плавно смещается между ступенями пентатоники раз в 2–3 минуты, меняя эмоциональный окрас всего аккорда.
3. **Детерминизм по `seed`:** Все случайные интервалы, питч-сдвиги ($\pm 3\%$) и выбор нот управляются потоком `keyRNG(mapSeedKey · 'audio')`. Два игрока на одной трассе слышат гармонически идентичное звучание.

## 3. Look-Ahead планировщик аудио-событий (Web Audio Scheduler)

События планируются с упреждением на точных аппаратных часах `audioCtx.currentTime`:

```javascript
const LOOK_AHEAD_MS = 100;
const SCHEDULE_INTERVAL_MS = 25;

function scheduleAudio(nowAudioTime) {
  while (nextNoteTime < nowAudioTime + LOOK_AHEAD_MS / 1000) {
    playProceduralNote(nextNoteTime, currentScale);
    nextNoteTime += getDeterministicInterval();
  }
}
```
