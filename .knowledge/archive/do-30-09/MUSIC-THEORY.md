# Музыкальная теория — проверенные факты для скинов/визуала (не о движке звука)

Отдельно от `AUDIO-SYSTEM.md` (тот — про процедурный звуковой движок игры, реализация).
Этот файл — исследовательский, по образцу `GENERATIVE-GEOMETRY.md`/`COLOR-THEORY.md`:
реальные, факт-чекнутые музыкальные/акустические явления как источник для будущих
визуальных скинов/следов/вспышек. Начат 06.09.2026 по прямому запросу владельца
(«изучай везде — химия, физика, музыка»).

## Партия 06.09.2026 — первая (`macet_music.html`, одобрено владельцем)

- **Обертоновый ряд** — реальные частоты f, 2f, 3f, 4f... (целые кратные основной
  частоты). Амплитуда естественно убывает примерно как 1/n у многих реальных тембров —
  честно помечено как типичное поведение, не универсальный закон для всех инструментов.
- **Кривые Лиссажу / гармонограф** — уже были исследованы раньше в этой сессии
  (`GENERATIVE-GEOMETRY.md`), но не построены. x=A·sin(at+δ), y=B·sin(bt), отношение a:b —
  это и есть музыкальный интервал (3:2=квинта, 4:3=кварта, 2:1=октава). Исследовано
  Боудичем (1815), подробно Жюлем Лиссажу (1857).
- **Хладниевы фигуры / киматика** — тоже уже исследованы раньше, не построены. Эрнст
  Хладни, 1787. Для КРУГЛОЙ пластины — точная формула через нули функций Бесселя J_n;
  для любой другой формы пластины общей формулы нет, только численная симуляция. Функция
  Бесселя реализована усечённым рядом, ПРОВЕРЕНА числом против известных нулей (J0:
  2.4048/5.5201, J1: 3.8317, J2: 5.1356 — совпало с точностью 4 знака).
- **Пифагорова комма** — 12 чистых квинт (отношение 3:2) НЕ равны в точности 7 октавам:
  (3/2)¹²/2⁷ ≠ 1, разница ровно 23.46 цента (проверено числом через логарифм, не «примерно
  чуть-чуть»). Это и есть исторический повод для равномерной темперации — без нее круг
  квинт физически не замыкается. Равномерно-темперированная квинта 2^(7/12)≈1.4983 против
  чистой 3/2=1.5 — расхождение ≈1.96 цента на каждый шаг.

## Урок геометрии корпуса — распространён и на музыкальные карточки

Тот же класс ошибок из `feedback_macet_geometry_pitfalls.md` (пункты 7-10) применён
проактивно с самого начала этой партии: все 4 формы проверены тестом «точка внутри
многоугольника» ДО показа (безопасный радиус ≈7 при cy=-4 для радиальных узоров), ни
одной правки после показа не потребовалось — сработала профилактика.

## Партия 06.09.2026, вторая — «глубже в уже начатое» (`macet_deeper.html`, одобрено)

- **Колесо созвучий (кривая диссонанса Пломпа-Левелта, 1965)** — параметризация Sethares:
  d(x)=e^(−3.5x)−e^(−5.75x), x=s·|f2−f1|, s=0.24/(0.0207·f1+18.96). ПРОВЕРЕНО числом: пик
  шероховатости при x≈0.221 (источник — «около 1/4 критической полосы», совпало), унисон
  даёт d=0. Честно другой, более тонкий факт, чем целочисленный пифагорейский круг квинт
  (партия 1) — непрерывная психоакустическая шероховатость, не отношения целых чисел.

## В очереди — не начато

- Родственные направления в музыке: консонанс/диссонанс через простые числовые отношения
  (уже частично затронуто через комму/Лиссажу, можно углубить), реальные акустические
  резонансы (резонанс Гельмгольца, стоячие волны в трубе/струне), может быть —
  визуализация спектрограммы реального звука (если найдётся честный алгоритм, не имитация).
