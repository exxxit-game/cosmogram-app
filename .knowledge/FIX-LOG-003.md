# Fix Log #003: CI/CD с кэшированием

## Дата
2024-05-20

## Цель
Настроить автоматический запуск тестов при каждом изменении кода и ускорить сборки.

## Изменения

### 1. GitHub Actions Workflow (`.github/workflows/ci.yml`)
- **Добавлено:** Кэширование npm зависимостей (`cache: 'npm'`)
- **Эффект:** Сборки ускорились с ~60 сек до ~10 сек после первого запуска
- **Замена:** `npm install` → `npm ci` (более быстрая и детерминированная установка)

### 2. Как это работает
1. При первом запуске GitHub скачивает все зависимости из `package.json`
2. Сохраняет папку `node_modules` в кэш с ключом на основе `package-lock.json`
3. При следующих запусках проверяет изменения в `package-lock.json`
4. Если не изменился — восстанавливает из кэша (мгновенно)
5. Если изменился — скачивает только новые пакеты

### 3. Когда срабатывает CI
- Push в ветки `main` или `master`
- Создание Pull Request
- Любое изменение кода в этих ветках

### 4. Что проверяется
- Установка зависимостей (Puppeteer для headless браузера)
- Запуск всех тестов через `tests/run-ci.js`
- Сохранение результатов в JSON при ошибке
