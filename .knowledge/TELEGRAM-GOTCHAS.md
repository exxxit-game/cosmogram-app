# ⚠️ Cosmogram — Telegram Mini Apps Gotchas & Platform Limits

> **Scope:** Practical edge cases, mobile WebView caveats, API limits and battle-tested mitigations for Telegram Mini Apps.

---

## 1. Лимиты `CloudStorage` (Критично для `sync.js`)

| Ограничение | Лимит Telegram API | Что произойдет при нарушении | Митигация в Cosmogram |
| :--- | :--- | :--- | :--- |
| **Количество ключей** | **1024 ключа** на пользователя | Запись падает с ошибкой | Хранить только агрегированные максимумы |
| **Размер значения** | **4096 байт (4 КБ)** на ключ | Тихий отказ сохранения | Ленты призраков (26 КБ) писать в `localStorage` и сервер |
| **Символы ключа** | `A-Z, a-z, 0-9, _, -` | Ошибка валидации | Строгие строковые идентификаторы |

## 2. Специфика iOS WKWebView & Android WebView

### 2.1 Случайный свайп закрытия (Closing Swipe)
- На iOS свайп вниз закрывает модальное окно Mini App.
- **Решение:** Вызов `Telegram.WebApp.enableClosingConfirmation()` при старте игры («Погружение», v1.58.0) + `touch-action: none` на Canvas.

### 2.2 «Чёлка» и Dynamic Island
- Системный UI перекрывает HUD в полноэкранном режиме `requestFullscreen()`.
- **Решение:** Использовать переменные `var(--tg-safe-area-inset-top)` в стилях HUD контейнера.

### 2.3 Задержка Haptics на Android
- На некоторых оболочках Android прямой вызов `impactOccurred` имеет лаг до 30мс.
- **Решение:** Двухканальный виброэфир — сначала Telegram Haptics, резервный канал — системный `navigator.vibrate([50])`.

### 2.4 Потеря WebGL/Canvas контекста при входящем звонке
- Аудио-контекст переходит в состояние `'interrupted'`.
- **Решение:** Сторож в `core.js` проверяет и `suspended`, и `interrupted`, вызывая `resume()` по возвращении фокуса.

## 3. Распространение, рефералы и правила платформы

### 3.1 Deep-link `startapp`
- Параметр до 64 символов, разрешены `A-Z, a-z, 0-9, _, -`.
- Рекомендуется base64url для бинарных данных.
- Вне Telegram (браузер) параметр может не прокинуться, если нет клиента.

### 3.2 `shareToStory`
- Открывает нативный редактор историй с медиа по HTTPS-ссылке.
- Подпись: 200 символов для обычных, 2048 для премиум.
- Не содержит ссылку на игру — это снижает фильтрацию алгоритмами (как в Wordle).

### 3.3 `switchInlineQuery`
- Вставляет запрос в поле ввода чата, требует включения Inline Mode у бота.

### 3.4 `requestWriteAccess`
- Запрашивает разрешение боту писать пользователю.
- После получения не злоупотребляйте — спам запрещён правилами.

### 3.5 Реферальные механики
- Одноуровневое приглашение не запрещено, но двухуровневое (MLM) и накрутка (social growth manipulation) — запрещены.
- Не давайте бонусов за сам факт шеринга — это ведёт к спаму (опыт WeChat).
- Давайте награду только за результат приглашённого (честный забег).

### 3.6 Правила Telegram для разработчиков ботов (цитаты)
- Запрещены MLM, социальная манипуляция, фишинг, спам, обход rate-limit.
- Разрешено до 30 сообщений/с бесплатно, далее платно.

## 4. Блокировки и доступность в РФ
- Cloudflare (на котором сидит Supabase) блокируется в России с 2025 (обрыв после 16 КБ).
- GitHub Pages периодически деградирует (май 2026, ~16% сбоев).
- Держите резервный CDN/зеркало.

## 5. Прочее
- `disableVerticalSwipes()` (Bot API 7.7+) или трюк с `scrollTo(0,1)` для предотвращения сворачивания Mini App при свайпе вниз.
- На Android WebView Telegram FPS может быть ниже, чем в Chrome — тестируйте внутри клиента.
- `ScreenOrientation.lock()` не поддерживается в Safari/WebKit.
- Fullscreen Web API не работает внутри Mini App — используйте Telegram-методы.
- `Telegram.WebApp.HapticFeedback` может не работать на части Android-сборок (issue #28).

## 6. Origin hardening — заработало 20.07.2026
- С 20 июля 2026 Telegram **автоматически запретил вызовы методов Mini App (`Telegram.WebApp.*`) с любого origin, кроме зарегистрированного домена Mini App**. Отключить можно только через @BotFather — и это передаёт всю ответственность вам. Держать защиту включённой.
- Ломается только вызов моста, НЕ загрузка ассетов: картинки/шрифты/скрипты с CDN продолжат грузиться. Ломаются back button, haptics, fullscreen, CloudStorage и т.п. на страницах с другого origin.
- Origin = scheme + host + port. `example.com` и `www.example.com` — разные origin.
- Механизм — системный ответ на CVE-2024-33905 (угон Telegram-сессии через `web_app_open_link` с `javascript:` URL и `targetOrigin:'*'`, патч марта 2024).
- **Проверить сейчас:** все страницы, вызывающие `Telegram.WebApp`, должны жить на одном зарегистрированном домене. Одна страница на соседнем поддомене — и её кнопки молча умирают.

## 7. Научная база для платформенных решений
> **Из `anti-cheat-security` (ARTICLES/):** клиент — среда без доверия (Zero Client Trust). В JS-играх memory-editing нерелевантен (нет бинарника); реальная поверхность атаки — DevTools-консоль и перехват сетевых запросов. Защита правильно стоит на сервере: планка дуэли живёт в Supabase Edge, replay-валидация, потолок `SCORE_CEIL`. OWASP Game Security Framework v0.5.1 Level 1 — достаточен для одиночных игр с таблицей рекордов.

> **Из `webgl-vs-canvas` (ARTICLES/):** в Telegram Mini Apps (iOS WKWebView) WebGL несет риски: агрессивный `webglcontextlost` при нехватке памяти/сворачивании, десятки МБ видеопамяти под текстуры на Retina DPR=3, холодный старт +200–500 мс на слабых Android Go. **Вердикт:** оставаться на Canvas 2D с предрендерингом, Path2D-кэшем, целочисленными координатами. Перспектива — интерфейс `Renderer` (Strategy) для бесшовного подключения WebGL-слоя частиц при необходимости.
