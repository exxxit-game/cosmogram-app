# 🚀 Стратегия органического роста Cosmogram (2026)

> Миссия: рост через социальную валюту, мастерство и детерминированные ритуалы. Telegram — не App Store: витрины нет, рост идёт только через личные пересылки и чаты.

> **Риск зависимости от чужой платформы — не только теория (найдено 27.08.2026).** 4 августа
> 2026 Apple временно удалила Telegram из App Store из-за CSAM-контента, найденного на
> платформе (сам Cosmogram здесь ни при чём) — приложение вернули примерно через 90 минут.
> Cosmogram живёт внутри Telegram Mini App; при похожем, но более длительном инциденте
> единственная точка входа для игроков внутри Telegram пропадает независимо от качества
> самой игры. Не проверялось, есть ли уже готовый план действий на этот случай — сам факт
> инцидента подтверждает, что раздел «Telegram — не App Store» выше не абстрактный риск.

## 1. «Трасса дня» как виральный Wordle-эффект

| Механика Wordle | Реализация в Cosmogram | Что доделать |
|---|---|---|
| Единая загадка для всех | Трасса дня с суточным UTC-сидом | Явный таймер сброса, пуш «осталось X часов» |
| Дефицит (1 попытка) | Честный зачёт с первой попытки | Подать как фичу, а не ограничение |
| Шеринг без спойлеров | Карточка `card.js` | Карточка самодостаточна («Побей меня»), без ссылки в посте |
| Социальное доказательство | — | «Уже сыграли сегодня N человек» в интерфейсе |

Расчёт вирусного цикла Wordle: 10% делятся → ~100 показов на репост → ~10% конверсия = удвоение базы каждые ~11 дней. Это арифметика, не магия.

> **Подход из научного материала:** описание генерации траекторий в
> статье `procedural-generation` (ARTICLES/) позволяет строить путь
> incremental‑шагами, при этом каждый следующий сегмент зависит только от
> предыдущего и текущего сида, что гарантирует детерминизм при любом
> количестве перезапусков.
> **Дополнительное подтверждение из мобильного опыта (Tencent Cloud/CSDN):**
> В sandbox-средах (WeChat Mini Games, мобильные Safari/Chrome) основная причина GC‑фризов — утекшие текстуры при смене ориентации экрана или смены сцен. Обязательно вызывайте `.clear()` или обнуляйте ссылки на неиспользуемые `ImageBitmap` / `OffscreenCanvas` *снаружи* игрового цикла, чтобы GC мог их уничтожить.

## 2. Почему люди делятся (STEPPS, Jonah Berger)

Социальная валюта (скилл-флекс), триггеры (общее время выхода трассы), эмоция (восторг, не спокойствие), публичность (стримы, чаты), практическая ценность (место среди друзей), история (крючок в одном предложении).

## 3. Нативные примитивы Telegram

- `shareToStory` — нативный редактор историй; подпись 200 символов (2048 премиум); без ссылки — меньше фильтрации.
- `startapp` deep-link — **максимум 64 символа**, только `A-Z a-z 0-9 _ -`. По ссылке делимся сидом, а не лентой.
- `switchInlineQuery`, `requestWriteAccess` (не злоупотреблять), `shareMessage` + `savePreparedInlineMessage` (Bot API 8.0) — rich-карточка вызова в любой чат.

## 4. Пять шагов вирусной петли

1. **Карточка объясняет себя за 2 секунды** — яркая, понятная без пояснений, фраза-триггер («Побей меня»).
2. **Трасса дня — явный дефицитный ритуал** — обратный отсчёт, напоминание, счётчик сыгравших.
3. **`shareToStory` + `startapp`** — кнопка после хорошего забега, в описание зашита реферальная ссылка.
4. **Избирательный триггер шеринга** — только в моменты гордости: личный рекорд, обгон призрака друга, топ дня, красивый «впритык». НЕ после каждого забега.
5. **Обоюдная реферальная награда с анти-абузом** — награда только за честный результат приглашённого, с первого дня лимиты.

## 5. Этика и правила платформы (жёсткие границы)

- **Награда за сам факт «поделился» запрещена** — это «social growth manipulation» по правилам Telegram; WeChat запретил то же в 2019: порождает спам. Награждаем только результат приглашённого.
- Многоуровневые схемы (MLM) запрещены; одноуровневое приглашение — ок.
- Без спама: `requestWriteAccess` не превращать в рассылку.
- **152-ФЗ:** никнейм и аватар — персональные данные; с 01.03.2021 молчание ≠ согласие. Публичный топ с именами/аватарами требует отдельного опт-ина; показывать псевдоним, запрашивать согласие явно.
- Карточка без прямой ссылки — репост живёт дольше, алгоритмы не глушат.

## 6. ⚠️ Критично: предсказуемость сида дня (находка 14.08)

Ключ дня считается детерминированно из даты UTC — завтрашняя трасса вычислима уже сегодня (прецедент: список слов Wordle лежал в клиентском JS, появились «решатели»). Это конфликт с честностью Хартии.

Варианты:
1. **Серверный секрет дня** — ключ = HMAC(дата, серверный_секрет); клиент получает геометрию, а не сид.
2. **Публикация постфактум** — после конца суток публиковать сид («зерно-памятник»): верификация прошлого + контент-повод «трасса вторника была вот такая».
3. **Гибрид (рекомендуется)** — серверный секрет до конца суток, после — публикация сида в архиве трасс. Закрывает дыру предвычисления и создаёт вторичный виральный повод.

## 7. Чего НЕ делать

- Не копировать playbook tap-to-earn (Notcoin) — модель хайпа остывает; брать только урок «реферальная ссылка в диалог работает».
- Не переносить стратегии Discord/Twitter (кейс: 50k подписчиков Discord → 800 активных в Telegram).
- Не надеяться на поиск — в Telegram его нет.

## 8. Итог

Эффект «каждый 5-й хочет рассказать» даёт совокупность: избирательный триггер + самодостаточная карточка + дефицит на виду + путь «поделился → новый игрок» в один тап. Архитектура (общий сид, честность, card.js) — уже готовый фундамент.

### 9. Научная база для виральной механики Трассы дня

> **Из `procedural-generation` (ARTICLES/):** детерминированная генерация траекторий через `mulberry32` + `withTrack` позволяет строить путь incremental‑шагами — каждый следующий сегмент зависит только от предыдущего и текущего сида. Это гарантирует детерминизм при любом количестве перезапусков и делает «Трассу дня» честной для всех пилотов планеты.

> **Из `game-programming-patterns` (ARTICLES/):** паттерн **Game Loop с Fixed Timestep** (Glenn Fiedler + Robert Nystrom) с защитой от спирали смерти (`dt > 0.25` clamp, лимит catch-up шагов) уже реализован в `game.js`. Это фундамент для стабильного воспроизведения одной и той же трассы на 60/120 Hz экранах.

> **Ключевой вывод:** архитектура (общий UTC-сид + детерминизм + `card.js`) — уже готовый фундамент Wordle-эффекта. Не хватает только ритуала «поделился в один тап» (shareToStory + startapp) и явного таймера сброса в UI.

## Площадки дистрибуции (тиры, проверено по документам)

| Тир | Площадки | Условие Хартии |
|---|---|---|
| 1 (сразу) | itch.io, Poki/CrazyGames, Newgrounds, CodePen | нужна веб-версия (не Telegram-бот); порталы с принудительной рекламой — только если рекламу можно не включать |
| 2 (3–6 мес) | VK Mini Apps, Discord Activities, LINE, Internet Archive | VK/Discord: свой SDK; Discord рекламу не вставляет — полное соответствие Хартии; VK — компромисс |
| 3 (эксперименты) | TWA в Google Play ($25), Tizen/webOS ТВ, Meta Quest Browser | код переиспользуется почти полностью |

- Исключены: платформы с принудительной рекламой (Яндекс Игры, CrazyGames с обязательной
  рекламой), P2E/NFT — нарушают Хартию.
- В `sync.js` уже есть `dcAuth`/`syncDcAuth`/`dcWidget` — вход через Discord существует
  как код (v1.52.0 «Второй вход»), полноценная Discord Activity — отдельная работа поверх.
- Каждая новая площадка — отдельная зависимость: Stars-платежи и initData-подпись
  работают только внутри Telegram.
- **Платформа игр Telegram (`/newgame`) — вторая дверь, отложена.** Не Mini App, а обычный
  встроенный браузер. Теряется: полный экран, `addToHomeScreen` (лучший рычаг возврата),
  CloudStorage, safeArea (вся работа с чёлками), `DeviceOrientation` (гироскоп — «Полёт без
  рук» не работает), `initData` (вход по HMAC заменяется подписью `callback_query` — другой
  код). Правил монетизации на этой площадке нет, в changelog Bot API 2025–2026 по ней ни
  строки — Telegram её не развивает. Возвращаться только после закрытия потери прогресса,
  первой минуты и сида в бою; основной дверью не делать.

- **Что прямо запрещено:** двухуровневые реферальные цепочки («получи за то, что
  приглашённый тоже пригласил») подпадают под «MLM or ponzi schemes»; автоматизация
  или покупка приглашений — под «social growth manipulation» (раздел 5.2 ToS).
- **Что разрешено:** одноуровневое «ты пригласил — ты получил» явно не запрещено.
- **Рассылка:** до 30 сообщений/сек бесплатно тем, кто дал разрешение; сверх лимита —
  0,1 Stars за сообщение (раздел 6.2.5).
- Следствие для плана роста: реферальная механика допустима, но любая награда
  должна быть только за прямое приглашение, без уровней, и без ферм аккаунтов.

- **В Telegram нет витрины.** Задокументированный случай: студия с миллиардной базой
  в сторах набрала в Telegram-мини-игре 17К игроков за 3 месяца, полагаясь на
  органический поиск, которого на платформе не существует.
- **Что растёт вместо витрины:** реферальные ссылки, долетающие прямо в диалог
  (startapp), и личные пересылки карточки результата. Рост Wordle без одного доллара
  рекламы — та же конструкция: синхронность (одна трасса дня), дефицит (одна попытка)
  и результат, которым хочется хвастаться. У Космограммы архитектура уже есть: общий
  сид + честность + card.js. Не хватает только ритуала «поделился» в один тап.
- **Рынок 2026:** хайп tap-to-earn остыл, бюджеты ушли в Telegram Ads; растут игры,
  где вовлечённость держится на механике, а не на спекулятивной награде. Позиция
  Космограммы — преимущество.
- **Триггер делиться — избирательный:** предлагать шеринг только в момент реального
  личного рекорда, иначе приедается (эффект «каждый пятый» — совокупность, не один пункт).
## Платформы: стоп-лист (противоречит Хартии)

| Платформа | Почему не подходит |
|---|---|
| Крипто-игры (Play-to-Earn) | Против Хартии: лутбоксы, NFT, спекуляция |
| NFT-игры | «Купи NFT, чтобы играть» — нарушение принципа «одно небо для всех» |
| Roblox | Требует Lua, нет HTML5 Canvas |
| Minecraft | Другая технология, не подходит |
| Платформа игр Telegram (`/newgame`) | Обычный браузер внутри Telegram, а не Mini App |

**Facebook Gaming — пересмотрено 27.08.2026.** Раньше стоял в этом стоп-листе
(«токсичен для приватности»). Владелец явно решил пересмотреть запрет. Отдельная
техническая оговорка, не связанная с самим пересмотром: Meta сворачивает именно
тот веб-движок игр (`FBInstant` SDK), под который обычно пишут интеграцию —
срок миграции на новую систему («Network Enabled Zero Permissions») до
30 сентября 2026. Реальная интеграция, если до неё дойдёт, должна целиться в
то, что придёт на замену, а не в `FBInstant.initializeAsync()` и подобное.

### Крипто/NFT-инфраструктура — не автоматический конфликт (уточнение 01.09.2026)

**Важное уточнение владельца, чтобы не повторить ошибку:** Хартия НЕ запрещает
крипто-кошельки, NFT или блокчейн как технологию — в `CHARTER.md` явно запрещены
только реклама (ст.1) и лутбоксы/рандом-за-деньги (ст.3). Первый черновик этого
раздела ошибочно расширил «без крипто-спекуляции» до «требует кошелёк — уже
нарушение» и отправил Farcaster Frames/Lens Protocol в стоп-лист только за это —
неверно. Настоящая граница владельца: **против скама, мемкоинов, паразитирования
и отжимания чужих денег; не против крипты как явления** (уважение к биткоину
названо прямо) — в игру планируются NFT-награды/подарки через Telegram (уже
технически доступно).

- **Farcaster Frames** — не в стоп-листе, перепроверено 01.09.2026. Базовая
  технология легитимна: идентичность (FID) — это аккаунт, не ставка; читать
  ленту и пользоваться ядром взаимодействия можно без токенов вообще (уже есть
  примеры бесплатных нефинансовых Frame-игр — Framedl/Wordle-клон, 2048,
  «камень-ножницы-бумага»). Кошелёк запрашивается SDK только под конкретное
  действие (минт, транзакция), не поголовно. Мемкоин-репутация реальна, но
  внешняя: **Clanker** (бот для минта ERC-20 токенов на Base, влившийся в орбиту
  Farcaster в окт.2025) гонит спекуляцию — но это отдельная надстройка, автору
  Frame не обязательно её касаться. [ДОК] docs.farcaster.xyz
  **Вердикт: подходит — базовая технология легитимна и бесплатна для игрока;
  не строить ничего, что касается Clanker/Base-мемкоин-тулинга конкретно.**
- **Lens Protocol** — не в стоп-листе, перепроверено 01.09.2026. **GHO — реальный
  overcollateralized стейблкоин от Aave** (устоявшегося DeFi-протокола), привязан
  к $1, используется как газ-токен именно ради ПРЕДСКАЗУЕМОСТИ комиссии — это
  структурно противоположность мемкоину, та же роль, что у ETH на газ, только
  без волатильности. Просмотр/чтение сети токенов не требует; платный фолловинг
  — опция конкретного профиля (настраивается его владельцем), не общий барьер
  протокола. [ДОК] aave.com, theblock.co
  **Вердикт: подходит — легитимная инфраструктура, обычные технические оговорки,
  без спекулятивной/скам-экономики.**
- Существующие строки стоп-листа «Крипто-игры (Play-to-Earn)» и «NFT-игры» (см.
  ниже) не меняются — они были и остаются про другое: P2E — это извлечение денег
  у новых игроков ради старых (тот самый паразитизм), «купи NFT, чтобы играть» —
  это платный вход, нарушающий «одно небо для всех». Обе формулировки уже били
  точно в цель, тронуты не были.

## Видео-экспорт: архитектура (см. FLIGHT-CINEMA-ARCHITECTURE.md)

- **Не экранировать экран.** Рендерим из детерминированной ленты в фиксированный формат.
- **Эталон:** 1080×1920 (9:16), 30 fps, H.264/AAC, ≤60 сек.
- **Технология:** WebCodecs (`VideoEncoder` + `mp4-muxer`) в Web Worker — до 10×
  быстрее реального времени. Фолбэк: `MediaRecorder + canvas.captureStream` → `ffmpeg.wasm`.
- **Доставка:** загрузка MP4 на HTTPS CDN → `Telegram.WebApp.shareToStory(cdnUrl, {text})`.
- **Server-side вариант (v2):** отправка seed + tape на headless-рендерер — байт-в-байт
  одинаковый результат на всех устройствах.
- **Видео в историю:** `shareToStory(media_url, {text})` — экспорт MP4 (1080×1920, 9:16) из детерминированной ленты через WebCodecs pipeline (см. PERFORMANCE.md §2.23). Поддержка: Chrome/Edge/Safari 13.1+, fallback через `MediaRecorder` + `ffmpeg.wasm`.
