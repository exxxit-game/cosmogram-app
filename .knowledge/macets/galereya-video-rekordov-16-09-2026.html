16.09.2026 — компактная дверь на главном экране + экран галереи за ней

Это макет. Ничего не перенесено в игру — жду направление, потом «да».
Было раньше: одна широкая карточка «Ваш первый полёт / Сохранено навсегда» на главном экране — превью-видео 52×52, заголовок, подзаголовок, кнопка «Удалить» (index.html:3544, #firstFlightCard). Хранился только один-единственный клип — самый первый полёт за всё время.

Стало (твои слова сегодня): «не просто одно видео» — галерея: «Первый полёт» сохраняется всегда отдельно, плюс по одному видео-рекорду на каждый из 7 режимов, новый рекорд заменяет старое видео этого же режима. Вход в галерею — «не больше места, чем одна иконка или кнопка».

Бейдж-число сверху справа — сколько видео уже накоплено (пример: «8» — все режимы + первый полёт). Показывает, что там есть что смотреть, без текста.

2. Экран галереи — открывается по тапу

—
«Первый полёт» — всегда первая карточка, с золотой плашкой-закрепом, никогда не заменяется новым рекордом (твои слова: «первый полёт тоже сохраняется»).
—
Дальше — 7 карточек, по одной на каждый режим карусели (те же названия и порядок, что на главном экране: Score Attack / Небо месяца / Speedrun / Caravan / Без касаний / Биатлон / Эстафета). Новый рекорд в режиме — новое видео заменяет старое (твои слова: «новый рекорд заменяет старое видео»).
—
Режим без единого рекорда — пустая карточка-заглушка (пунктир), а не пропуск места: сетка остаётся ровной 2×4, видно сколько ещё предстоит.

Отдельно, не в этом макете: запись видео на КАЖДЫЙ рекорд режима (не только на первый полёт) — это тот же механизм VideoEncoder, который в августе реально подвешивал слабые Android (аварийный рубильник CINEMA_DISABLED, js/cinema.js) и сейчас включён один раз на «первый полёт». Ты выбрал «сперва отдельно проверить нагрузку» — макет описывает только ЭКРАНЫ, включение записи по всем режимам — отдельный шаг после проверки, не одновременно с этим макетом.
