> **Дополнительные новые факты (2024–2026 из многократного опроса практик):**

> 1. **Китайский опыт (H5/Mobile):** GC‑фризы вызываются утекшими текстур при смене ориентации/сцен. Необходимо `.clear()` ссылок на `ImageBitmap` / `OffscreenCanvas` снаружи игрового цикла. Пулы объектов распространять на UI и состояния игры.

> **Современные браузерные паттерны (2024–2026):**
> - **Struct of Arrays (SoA):** Использование TypedArrays (`posX`, `posY`, `active`) вместо объектных массивов исключает скрытые аллокации и позволяет векторные оптимизации V8.
> - **ImageBitmap + Transferable:** `createImageBitmap()` + передача как Transferable Object (через `postMessage(..., [bitmap])`) — zero‑copy передача текстур из Web Worker.
> - **WebCodecs API:** Для видеорендеринга использовать `decodeVideoFrame()` с аппаратным ускорением и `drawImage()` zero‑copy.
> - **Инкрементальный GC:** Единые `ArrayBuffer` через TypedArrays воспринимаются V8 как один компактный массив, снижая частоту инкрементального GC.
