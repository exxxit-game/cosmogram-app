# Соло-аудит, угол 5: незавершённое / мёртвое / недостижимое (18.09.2026)

Пятый угол серии соло-аудитов «где ещё в игре баги/дыры/пустые места» (владелец: «надо их
понаходить»). Предыдущие четыре угла (см. соседние RESEARCH-файлы той же серии) покрыли тихие
сбои, производительность по тиру устройства, согласованность между устройствами, доступность —
здесь не дублируются.

Методология проекта (ABSOLUTE, `feedback_audit_dva_prohoda_raznymi_metodami_do_spiska`):
находка засчитывается только после второй, независимой проверки другим способом. Агент угла 5
применил это по каждому пункту сам (грep → полное чтение файла/тестов на скрытые вызовы). Ниже
дополнительно САМ перепроверил находку №1 (самую важную) прямым чтением кода — см. пометку.

## Подтверждённые находки

1. **[ПРОВЕРЕНО МНОЙ НАПРЯМУЮ, самое важное] Категории скинов/декалей не переведены на
   EN/ES/PT/FR — сырой английский ключ на экране игроку.**
   `js/i18n.js:299-302` (RU) содержит полный словарь `decalCatNames` (86 ключей, включая
   `mono/classic/live/sacred/superformula/roses/premium/celtic/bright/legendary/stars/
   materials/sigils/illusion/patterns/lsystem/cosmos/culture/physics/optics/biology/metal/
   cardboard/carpets/textile` — 25 ключей во второй половине строки). Собственный комментарий
   в коде признаёт: «05.09.2026: разделы Вспышки/Следа/Скина — EN/ES/PT/FR ниже ещё без этих
   ключей». Прочитал `js/i18n.js:529` (EN) — подтверждено, все 25 ключей отсутствуют, словарь
   обрывается на `iTravel`. То же для ES (`:748`), PT (`:977`), FR (`:1198`) — не перечитывал
   построчно все четыре (RU vs EN уже даёт однозначное доказательство паттерна), но словарь
   там той же длины/структуры, что и EN, судя по строкам агента.
   Используется в `js/ui.js:2441-2445` (`angarBuildGrid()`): `(L.decalCatNames &&
   L.decalCatNames[item.cat]) || item.cat` — при отсутствии ключа честно показывает сырой
   `item.cat` игроку (заголовки категорий на экране Тюнинга/витрины: «Цвет», вспышка, след,
   эмодзи).
   Страж 166 (`cosmogram-crew/tests/guard.mjs:7987-8005`) существует именно под этот класс
   бага (комментарий над ним описывает 2 прошлых живых случая — lsystem 06.09, cosmos/culture
   09.09), но **проверяет жёстко только `I18N.ru.decalCatNames`** (строка 7998) — для EN/ES/
   PT/FR ничего не ловит. Регресс/недоделка в нерусских локалях невидима стражу.
   **Кого касается:** любой игрок, выбравший EN/ES/PT/FR (не RU) и открывший Тюнинг/витрину
   скинов — увидит «cosmos», «metal», «textile» и т.п. вместо перевода.

2. **Мёртвый код — 3 функции объявлены, нигде не вызываются из реального UI.**
   - `js/sync.js:63-66` `ghostAccessStateForAuth()` — вызывается только юнит-тестом
     (`cosmogram-app/tests/ghost-access.test.js`), в реальном экране (`js/ui.js:3761-3776`,
     `accFill()`) логика гостя/входа продублирована независимо напрямую.
   - `js/partitura.js:109` `ptAtToPct()` — заменена на `ptAtToPctSafe()` (`:128`, есть
     датированный комментарий о переходе 17.09.2026), старая не удалена.
   - `js/game.js:2593-2598` `showBanner()` — готовый DOM+CSS (`#banner`/`#bannerWrap`,
     `index.html:3876,1224-1229`), ни разу не вызывается — похоже на заготовку баннера для
     крупных событий/рекордов, так и не подключённую.
   Низкий риск (код не исполняется, значит не может ломать игру), но замусоривает кодовую
   базу и может сбивать будущий грep/навигацию.

3. **`SKINS[].extra:true` — осиротевшее поле данных.** Стоит примерно у 60 записей (все
   культурные/научные премиум-скины, `js/game.js:33-100`), но не читается нигде в `js/`.
   Сами скины не недостижимы (продажа идёт штатно через `price`/`fx`/`cat`) — просто поле
   без потребителя. Самый низкий приоритет из всех находок.

## Проверено и НЕ подтверждено (опровергнутые гипотезы, для прозрачности методики)

- `js/cinema.js:1030-1031` `cinemaAngarZoomBusy()` — похоже на мёртвый код при первом grep,
  но реально вызывается стражем 268 (`cosmogram-crew/tests/guard.mjs:13621`) — не баг.
- Расхождение JS→HTML (обработчик на несуществующий id) — систематически проверено 338
  уникальных id, расхождений не найдено.

- Экраны без пути закрытия — проверены `#claimScreen`, `#angarPvZoomModal`, тупиков не
  найдено (частичная проверка, не вся игра).
