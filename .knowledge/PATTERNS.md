# 🧩 Cosmogram — Architectural & Code Patterns

> **Scope:** Core software design patterns used throughout the Cosmogram engine.

---

## 1. Паттерн `withTrack` (Изоляция детерминированных потоков)

Паттерн предотвращает утечку случайных чисел между различными категориями спавна (препятствия, звёзды, бонусы):

```javascript
// js/core.js
let mapRNG = keyRNG(mapSeedKey);
let mapSeq = { ob: 0, st: 0, pw: 0 };

function withTrack(kind, fn) {
  const prev = mapRNG;
  // Генерируем уникальный seed-хэш для текущей категории и номера сущности
  mapRNG = keyRNG(mapSeedKey + '·' + kind + '·' + (mapSeq[kind]++));
  try {
    return fn();
  } finally {
    mapRNG = prev; // Гарантированный возврат исходного генератора
  }
}
```

## 2. Паттерн `Swap-and-Pop` (O(1) удаление без мусора)

Вместо медленного метода `Array.prototype.splice()`, который вызывает сдвиг всех элементов массива и аллокации:

```javascript
function killIdx(arr, i, pool) {
  const l = arr.length - 1;
  const o = arr[i];
  if (i < l) arr[i] = arr[l]; // Переносим последний элемент на место удаляемого
  arr.pop();                  // Быстрое удаление с конца за O(1)
  if (pool) pool.give(o);     // Возврат в пул памяти
}
```

## 3. Паттерн `Object Pool` со сбросом инвариантов

```javascript
function makePool(maxCap) {
  const free = [];
  return {
    take() {
      return free.pop() || {};
    },
    give(o) {
      if (free.length < maxCap) {
        // Обязательный сброс динамических ссылок для исключения утечек памяти
        o._tint = null;
        o._path = null;
        o._tg = null;
        o._tgk = undefined;
        free.push(o);
      }
    }
  };
}
```

## 4. Паттерн `Arbiter / Compass Court` (Арбитраж датчиков гироскопа)

Автоматическая калибровка и определение врущего гироскопа:
- Замер разброса показаний `LIVE_SPREAD`.
- Если датчик шлёт шум или заклинил на одной оси, штурвал плавно отбирается и передаётся сенсорному вводу пальца без рывка.
- Двусторонний замок: возврат управления пальцу происходит по первому касанию экрана.

---

## 5. Паттерн `Store-and-Forward` (Очередь телеметрии в `skymail.js`)

Асинхронная отправка сообщений об ошибках с защитой от флуда и сетевых сбоев:
- Окно вежливости 21 секунда (`OKNO = 21000`).
- Дедупликация ошибок за сессию через `Set`.
- При отсутствии сети сообщения ждут в локальной очереди `Store` и досылаются при следующем старте.
## 6. Паттерн Beacon Batching (батчинг маяков)
- Накопление нескольких писем в очереди и отправка одним HTTP-запросом.  
- Снижает число edge-вызовов и нагрузку на БД.  
- Реализация: очередь `pending`, таймер или триггер по размеру/времени, `flush()` отправляет всё за раз.
