# CosmoCoder — служебный чат разработчика. Настройка за 10 минут

Три файла:

- `worker.js` — код для Cloudflare Worker: прячет ключ Anthropic и стережёт вход;
- `dev-chat.html` — страница чата, лежит **в корне репозитория, рядом с `index.html`**;
- этот файл — инструкция.

**Это чат для экипажа, не для игроков.** Страница нигде не подключена к игровым экранам,
в меню не появится, попасть на неё можно только по прямой ссылке. Если однажды понадобится
ИИ для игроков — это другой разговор с другой ценой: потолки трат на каждого, защита от
злоупотреблений и правка `privacy.html`, где сейчас про передачу текстов третьей стороне
не сказано ни слова.

---

## Главное, что нужно понимать до первого клика

**Страница чата публичная.** Она лежит на GitHub Pages, её исходник открывается в браузере
двумя кликами. Значит адрес воркера, вписанный в неё, публичен по построению.

Отсюда два правила, которые и определяют всю настройку:

1. **Ключ Anthropic никогда не попадает в страницу.** Он живёт только в воркере. Ради этого
   воркер и существует.
2. **Проверки `Origin` недостаточно.** Заголовок `Origin` ставит браузер, а `curl` ставит
   любой. Поэтому вход закрыт вашим личным паролем `DEV_KEY`: страница спрашивает его один
   раз и держит в браузере, в репозиторий он не попадает никогда.

И третий слой, поверх всего: **поставьте месячный потолок трат в консоли Anthropic.** Он
переживёт утечку и ключа, и пароля. Проверку кладут туда, где её нельзя обойти.

## 1. Ключ Anthropic

`console.anthropic.com` → Settings → API Keys → Create Key. Скопируйте, начинается на `sk-ant-`.
**Никуда его не вставляйте, кроме поля Secret на шаге 3.** Ни в файлы, ни в переписку.

Там же поставьте месячный потолок трат. Начните с малого, поднять всегда успеете.

## 2. Придумайте личный пароль входа

Любая длинная строка, которую вы запомните или сохраните в менеджере паролей — например
из четырёх случайных слов. Это будет `DEV_KEY`: им открывается чат, и знать его должны
только вы.

## 3. Воркер на Cloudflare

1. `dash.cloudflare.com` → **Workers & Pages** → **Create** → **Create Worker**.
2. Имя, например `cosmocoder-proxy` → **Deploy** (пока задеплоится шаблон).
3. **Edit code** → выделить всё, удалить, вставить `worker.js` целиком → **Save and Deploy**.
4. **Settings** → **Variables and Secrets** → добавить четыре штуки:

| Имя | Тип | Значение |
|---|---|---|
| `ANTHROPIC_API_KEY` | **Secret** | ваш ключ `sk-ant-…` |
| `DEV_KEY` | **Secret** | ваш пароль из шага 2 |
| `ALLOWED_ORIGIN` | текст | `https://superduck77.github.io` |
| `MODEL` | текст | `claude-sonnet-5` |

5. **Save and Deploy** ещё раз.

`MODEL` вынесена в переменную намеренно: сменить модель — это правка одного поля в панели,
а не правка кода. Живые имена на сегодня: `claude-sonnet-5` (рабочая лошадь),
`claude-opus-5` (умнее и дороже), `claude-haiku-4-5` (дешёвая и быстрая).
**Не пишите `claude-sonnet-4-6`** — в первой версии воркера стояла именно она, такой модели
не существует, и API отвечал ошибкой.

## 4. Адрес воркера в страницу

Сверху на странице воркера будет адрес вида `https://cosmocoder-proxy.ваш-логин.workers.dev`.
Откройте `dev-chat.html`, найдите в конце файла:

```javascript
const CONFIG = {
  workerUrl: 'https://ВСТАВЬ-СВОЙ-АДРЕС.workers.dev',
};
```

и впишите свой адрес. **Пароль сюда не вписывать** — его спросит сама страница.

## 5. Заливка

`dev-chat.html` кладётся **в корень репозитория, рядом с `index.html`** — там, где `sw.js`
и манифесты. *(В первой версии инструкции было сказано «в папку `app/`» — для этого
репозитория неверно: в `app/` лежит только перенаправление, а игра в корне.)*

`worker.js` в репозитории нужен как история кода — работает он на Cloudflare.

## 6. Проверка

Откройте `https://superduck77.github.io/cosmogram-app/dev-chat.html`. Страница спросит пароль.
Спросите что-нибудь простое.

| Что видно | Что это значит |
|---|---|
| Ответ пришёл | Всё работает |
| «Не тот ключ» | Пароль разошёлся с `DEV_KEY` в панели. Внизу справа — «сменить ключ» |
| `not_found_error: model` | Опечатка в переменной `MODEL` |
| `credit balance is too low` | Кончились деньги на счету Anthropic |
| «Чужой origin» | `ALLOWED_ORIGIN` не совпал с адресом, откуда открыта страница |
| «Не достучался до Worker'а» | Адрес в `CONFIG.workerUrl` неверный или воркер не задеплоен |

Ошибки специально приходят словами: без этого «не работает» не отличить от «не тот пароль»,
«нет такой модели» и «кончились деньги».

## Стоимость

Sonnet — порядка $3 за миллион входных токенов и $15 за миллион выходных. Для чата на
несколько вопросов в день это доли цента за разговор. Cloudflare Workers бесплатны до
100 000 запросов в день. Настоящий риск не в цене разговора, а в открытой двери — поэтому
пароль и потолок.

## Что стережёт стенд

**Страж 133** проверяет, что ни ключ `sk-ant-…`, ни значение `DEV_KEY` не попали ни в один
отслеживаемый файл репозитория. Он краснеет на настоящем ключе и не краснеет на этой
инструкции, где написано «начинается на `sk-ant-`».

## Чего этот чат не умеет

- **Не видит ваш код.** Он знает устройство проекта из системного промпта в `worker.js`,
  но файлов не читает: спросите про конкретную строку — честно попросит показать код.
- **Не показывает ответ по мере печати.** Ответ приходит целиком, после паузы.
  Потоковая выдача — отдельная работа, если понадобится.
- **Не помнит вчерашний разговор.** Переписка живёт во вкладке; закрыли — забылось.
- **Не ограничивает частоту запросов сам.** Замок на входе — пароль; настоящий потолок
  расходов — месячный лимит в консоли Anthropic.
