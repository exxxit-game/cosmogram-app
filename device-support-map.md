# Космограмма — карта устройств: где уже работает, где можно добавить

## Уже работает, без единой правки кода

**Основное**
- Телефон — Android и iPhone, чёлки и Dynamic Island обойдены, полный экран
- Десктопный Telegram — Windows, Mac, Linux, руль мышью/клавиатурой/геймпадом
- Любой размер экрана — «Метр неба» масштабирует одинаково от маленького телефона до широкого монитора
- Экраны 4K+ — «Потолок листа» (2560px) бережёт кадры и батарею
- Высокогерцовые экраны (120/240+ Гц) — ввод берёт самый свежий сэмпл за кадр

**Неожиданные, но реальные — просто нужно рассказать**
- **ТВ-браузеры с пультом** — пульт транслируется в обычные события клавиатуры, работает тот же код, что слушает стрелки на компьютере
- **Портативные игровые ПК** (Steam Deck, ROG Ally, Legion Go) — Linux/Windows-браузер + встроенный геймпад
- **ТВ-приставки на Android** (Fire TV Stick, NVIDIA Shield, Chromecast с Google TV) — браузер + Bluetooth-геймпад
- **Ретро-геймпад-консоли на Android** (Anbernic, Retroid и подобные) — обычные Android-устройства в необычном корпусе
- **Скрытые браузеры игровых консолей** (PS4/PS5, Xbox) — технически доступны, глубоко спрятаны
- **VR-гарнитуры** (Meta Quest Browser) — плоский экран в виртуальном пространстве
- **Любой Bluetooth-геймпад, который распознаёт ОС** — не привязано к бренду, стандартный Gamepad API уже открыт для всех
- **Скрытый браузер Nintendo Switch** — неофициальный доступ, для энтузиастов
- **Смарт-дисплеи бытовой техники** (Samsung Family Hub на Tizen, LG ThinQ на webOS) — не проверено лично, но технически должно открыться: настоящий браузерный движок внутри
- **Браузер автомобиля** (например, Tesla) — технически работает; осознанно не то, что стоит поощрять — только для пассажира на парковке, не за рулём
- **Простые двухосевые джойстики симуляторов полёта** — определяются и частично работают по счастливому совпадению осей X/Y

## Физически невозможно — не вопрос кода

- **E-ink ридеры** (Kindle и подобные) — экран обновляется секундами на кадр, реальный экшен-раннер там не может работать в принципе
- **Настоящие тамагочи, микроволновки без смарт-дисплея** — нет JS-движка, нет браузера, загрузить игру физически нечем

## Уже частично работает, но не полностью — вот где реальная работа

| Что | Статус сейчас | Что нужно |
|---|---|---|
| Полноценный HOTAS (джойстик авиасимулятора) | Определяется, читаются только оси 0/1 и кнопки 12–15 | Поддержка нескольких устройств разом (ручка + РУД отдельно), оси газа/рысканья, полный диапазон кнопок |
| AZERTY/QWERTZ раскладки клавиатуры | WASD не работает, стрелки работают | Проверка по `e.code`, не `e.key` |
| Очень узкие окна (iPad Slide Over, узкие десктоп-окна, сплит-скрин) | Нет нижнего предела масштаба | Минимальный `SC` с защитным сообщением вместо нерабочего микро-масштаба |
| Настройки/Сервисный центр с клавиатуры или пульта | Не получают фокус вообще | `tabindex="0"` + обработка Enter/Space на 21 кастомной кнопке |
| Установленная PWA (Android/десктоп) | Работает в браузере, не работает как установленное приложение | Снять рубильник `orientation:"portrait"` в манифесте, включить PWA обратно (когда будете готовы) |
| Мышь для точного руления | Только зажатая кнопка + относительное смещение | Pointer Lock API |
| Геймпад при столкновении | Молчит | `gamepad.vibrationActuator` не используется |
| Слабая/нестабильная связь при загрузке | Пустой экран без объяснений при сбое | Индикатор загрузки + `onerror` на скриптах |

## Вывод

Основа настолько правильно построена (Canvas 2D без WebGL, лёгкий вес, стандартные веб-API вместо проприетарных), что список «уже работает» оказался длиннее списка «нужно доделать» — и большая часть таблицы это уточнения существующей поддержки, а не новые системы с нуля.
