# Cosmogram

**Бумажный самолётик в Telegram.** Уворачивайся от астероидов, лови бонусы, ставь рекорды. Руль — палец или наклон телефона («Полёт без рук»).

▶️ **Играть:** https://l2s3d5nbtau2c.kimi.page/

Текущая версия: **v1.105.0 «Свет и дым»**. Имена версий у нас поэтичные — и это священно.

---

## Что умеет игра (на v1.105.0)

**Режимы полёта**
- **Классика** — бесконечный полёт на рекорд.
- **Трасса дня** — одна трасса на всех: коридор зачётных небес, у всех пилотов одинаковый.
- **Спидран** — короткий заезд на скорость.
- **Театр призраков** — зрительский автопилот: самолётик сам идёт по записанной ленте дня, руки со штурвала убраны.
- **Кузница** — конструктор собственного неба с пресетами.

**Полёт**
- Руль — палец; гироскоп «Полёт без рук» с калибровкой и судом компасов (врущий датчик осуждается автоматически и теряет штурвал).
- Шесть бонусов: щит, магнит, слоу-мо, жизнь, таран, сверхновая.
- Препятствия: камни (тона — база, лёд, железо), рукотворный мусор семьями (спутники и обломки по четыре лица), тёплая комета.
- Золотая звезда дня — редкий снич: золотые искры догоняют героя.
- Живое небо «Планетарий»: метеор, маяк, станция светом и дымом, отметины пути, вспышка крыла, корма со скоростью, искры звезды.

**Вокруг полёта**
- Экран итогов с карточкой: поделиться в сторис или в чат, сохранить картинку.
- Достижения и рекорды; прогресс синхронизируется в облако Telegram.
- Ангар — витрина самолётика.
- Музыка и звуки синтезируются на борту — ни одного аудиофайла.
- Морзянка — виброотклик в такт событиям.
- Чёрный ящик — бортовой самописец для диагностики.
- Два языка: русский и английский.
- Автокачество: на слабом железе плавно, флагманам максимум — механика одинакова для всех.
- Работает офлайн (сервис-воркер); плакат «Вышло новое небо» честно предлагает обновление.

**Соревнование**
- **Топ пилотов** — таблица рекордов по категориям, живёт на сервере.
- **Дуэль** — вызов другу: побей планку его верифицированного рекорда.
- **Призраки** — полетай бок о бок с трассой чужого рекорда; владелец трека может его скрыть.
- **Трасса дня** — один зачётный коридор на всех пилотов мира.

**Экраны:** Старт → Режимы → Полёт → Итоги → Карточка; витрины — Достижения, Ангар, Кузница, Настройки; служебные — Пауза, Диагностика, Золотая звезда.

**Штурвалы — чем можно рулить (всё на борту, проверено кодом):**
- **Палец** — главный штурман.
- **Наклон телефона** — «Полёт без рук» с калибровкой и судом компасов.
- **Мышь** — руль с зажатой кнопкой (v1.99.0).
- **Клавиатура** — стрелки и WASD, обе раскладки: русская и английская.
- **Геймпад** — левый стик или крестовина рулят, кнопка A — старт/заново, Start — пауза; стыковка и отстыковка штурвала пишутся в чёрный ящик (v1.99.7).

**Устройства и экраны:**
- **Телефон** — главная сцена: Android и iPhone; вёрстка обходит чёлки и «остров» Dynamic Island; полноэкранный режим, кнопка «на домашний экран».
- **Десктопный Telegram** (Windows, Mac, Linux) — руль мышью, клавиатурой или геймпадом.
- **Экран любого размера:** мир меряется эталоном 390×844 и масштабируется («Метр неба»), поэтому игра выглядит одинаково на маленьком телефоне и широком мониторе.
- **Экраны-монстры 4K+:** холст честно ограничен «Потолком листа» — не больше 2560 px по длинной стороне, красота не съедает кадры и батарею.
- **Высокогерцовые экраны (120/240+ Гц):** ввод берёт самый свежий сэмпл за кадр; игра меряет паспорт экрана — частоту и цветовой охват — и подстраивается.
- **ТВ и пульт ДУ:** отдельной поддержки нет (Telegram Mini Apps на ТВ не живут) — но там, где есть браузер с геймпадом, геймпадный штурвал сработает.

## Уровни графики (три ступени + умный автомат)

- **Три тира по паспорту видеочипа:** слабый / средний / флагман. Вычисляется один раз и запоминается навсегда.
- **«Ультра» — только флагманскому тиру:** слабых и средних не дразним.
- **Адаптивный I.Q:** меряет длительность кадра прямо в полёте и приглушает украшения на слабом железе.
- **«Потолок листа»** — 2560 px против экранов-монстров.
- **Священно:** масштабируются только украшения. Механика, скорость и препятствия одинаковы для всех.
- В планах модуль «Мозг неба»: угадывать класс устройства сразу и переключать ступени только в тишине, никогда посреди атаки.

## Честная игра (что уже сделано против читеров)

- **«Протокол seed» (v1.99.9):** один сид = одна геометрия трассы на любом экране. Раньше широкий экран (вплоть до ТВ) статистически облегчал трассу — спавн растягивался по ширине. Теперь соревновательные небеса играют в эталонном коридоре 390 мер: ни растяжения, ни «безопасной полосы» у края.
- **Планка дуэли живёт на сервере:** в ссылке-вызове цифры нет — подделать нечего.
- **Сервер не отдаёт призрак сильнее верифицированного рекорда:** подделка трека бессмысленна.
- **Знак результата — после результата:** галочка «рекорд записан» загорается только после подтверждения записи.

## Равноправие пилотов

- **Нет доната, рекламы и тёмных паттернов.** Не появится без суда хартии.
- **Механика одинакова для всех устройств:** на старье плавно, флагманам красиво — но небо одно на всех.
- **Каждый игрок — голос, а не дойный аппарат.** В планах — дверь «Предложить идею» прямо из настроек.
- **«Небо для всех»** — модуль доступности стоит в очереди.

## Дорожная карта (порядок утверждён)

Ближние модули: **«Штурман по желанию»** (выключатель гироскопа) → **«Имена неба»** → **«Пульт итогов»** → **«Кино полёта»** (видео заезда в сторис) → **«Мозг неба»** (умное автокачество) → **«Галерея небес»** (фотонебо) → **«Понятные настройки»** (с дверью «Предложить идею») → **«Тёплый свет — мой»** → **«Телевизор трассы»** → **«Пульс гонки»**, **«Небо для всех»** → предпросмотр бота.

Полка идей: «Звезда-сюрприз» (седьмой бонус, всегда добрый), «Минеральная кожа камней» (лабрадоритовый огонь внутри камня), созвездие-самолётик (ждёт своего часа на полке).

## Хартия неба

Добавляем только то, что улучшает игру. Каждый игрок — голос, а не дойный аппарат.

Каждый новый элемент проходит суд четырёх вопросов:
1. Улучшает ли игру?
2. Читается ли с полёта?
3. Не пугает ли зря?
4. Не крадёт ли кадры?

Декор никогда не входит в коридор столкновений. Всё рукотворное в коридоре — честная угроза и обязано так выглядеть.

## Ценности

- **Ядро + Модули.** Одна функция за раз, маленькие шаги. Одно небо — одна мысль.
- **Красота никогда не в ущерб читаемости препятствий.** Приборы могут быть плоскими — мир не может.
- **Как родное для Telegram.** Дизайн, имена и описания — человеческим языком, без жаргона.
- **Честность.** Никаких тёмных паттернов; знак результата рисуется после результата.
- **Стражи раньше кода.** Тест пишется до кода: красный → зелёный. Доска из 43 стражей прогоняется трижды перед каждой сдачей.
- **Механика одинакова для всех.** На слабом железе масштабируются только украшения — препятствия никогда.

## Устройство сейфа

- `index.html` (корень) — табличка-перенаправление на живую игру, точка входа BotFather. **Не трогать.**
- `app/` — код игры (vanilla JS + canvas, без сборки).
- `app/releases/` — зипы версий (полные снимки).
- `Космограмма_v1.105.0_«Свет_и_дым»[1].zip` (корень) — полный снимок v1.105.0, залит вручную; отпечаток сверен с оригиналом.
- `app/js/vendor/telegram-web-app.js` — официальный мост Telegram. Не правим никогда; восстанавливается с https://telegram.org/js/telegram-web-app.js

## Ритуал разработки

Один модуль = один коммит = один пуш. Перед модулем — разбор цены (время и стоимость), перед визуальным изменением — макет. Большие задачи режутся на подмодули по ~200 строк. Полный файл целиком — только после предупреждения о стоимости.
