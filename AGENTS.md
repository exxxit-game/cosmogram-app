# AGENTS.md — Cosmogram

> Открытый стандарт (agents.md), общий для Claude Code, Cursor, Codex и других инструментов.
> Этот файл — точка входа. Он короткий нарочно: подробные правила живут в `.knowledge/`,
> здесь — только карта и самые жёсткие ограничения, которые нельзя пропустить.

## Что это за проект

Cosmogram — бесконечный вертикальный космический раннер-уклонялка, Telegram Mini App.
Vanilla JS (ES2022+) + Canvas 2D, без фреймворков и без шага сборки. Владелец — соло,
не программист. Цель — одинаковое качество от бюджетных Android-телефонов до 4K-экранов.

## Прежде чем что-либо делать

Прочитать в этом порядке: `.knowledge/AI-WORKFLOW.md` → `.knowledge/INDEX.md` →
`.knowledge/KNOWN-BUGS.md` + `.knowledge/ERROR-CATALOG.md` → `.knowledge/STYLE-GUIDE.md` →
`.knowledge/PERFORMANCE.md`. Это канон, объявленный в самих этих файлах — не переспрашивать.

## Жёсткие ограничения (полный текст — STYLE-GUIDE.md §6, LAWS.md)

- Ядро (`core.js`, `game.js`, `render.js`, `input.js`) — не трогать без явного «да» владельца.
- Никакого `Math.random()` вне `withTrack()` — только `mulberry32` по сиду.
- Никаких аллокаций (`new`, `{}`, массивы, `.map/.filter`) в горячем тике.
- Общая фраза владельца («сделай так-то») не разрешает додумывать конкретные числа/пороги —
  это отдельный вопрос с явными вариантами, ждать ответ, потом код.
- GitHub заливает только владелец. ИИ готовит правки, не пушит.
- Полный список правил и почему — `.knowledge/AI-WORKFLOW.md`, разделы 1 и 5.

## Команды
